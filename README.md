# Fastighet & Avloppsteknik Väst AB – webbplats

Ren HTML/CSS/JS. Öppna `index.html` i webbläsaren.

Innehåll, bilder och herovideo kommer från kundens befintliga Lovable-sajt (Elevate Studio). Typsnitt: Manrope och Inter (Google Fonts).

**Sektioner:** hero med video, tjänster, om oss, varför välja oss, minireningsverk (BioKube), arbetsgång, vanliga frågor, kontakt med formulär, sidfot.
