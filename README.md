# Nordbygg AB – demo

> ⚠️ **Fiktivt företag.** Pedagogiskt projekt som visar hur en modern bygg- och fastighetssajt är uppbyggd. Ingen koppling till något verkligt företag.

Ren HTML/CSS/JS. Öppna `index.html` i webbläsaren.

**Innehåll:** sticky header, hero med bakgrundsvideo, tjänstekort, uppräknande siffror, projektkort med hover-zoom, split-sektion, nyhetslista, footer och scroll-animationer.

**Media:** licensfria bilder från Unsplash och video från Pexels, länkade via deras CDN. Typsnitt: Manrope och Inter (Google Fonts, OFL).
